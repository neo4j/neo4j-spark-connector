[#_6_0_0]
== Version 6.0.0 (TBA)

[cols="1,2",options="header"]
|===
| Feature | Details

a|
label:breaking[]

First release supporting Spark 4.0 and 4.1.
| Fully supports Neo4j 5.0, 2025 and 2026. Dropped support official support for older Neo4j.

a|
label:breaking[]

Removed deprecated 5.x features
| Such as option `schema.optimization.type`, usage of `$stream.offset` in partitioned reads etc.

a|
label:new[]
label:feature[]

Expose cypher query tuning parameters
| With new spark options prefixed `cypher.tuning` you can apply `CYPHER` preambles for any connector action that interacts with Neo4j.

a|
label:new[]
label:feature[]

Provide your own
| With new spark options prefixed `cypher.tuning` you can apply `CYPHER` preambles for any connector action that interacts with Neo4j.

|===

[NOTE]
====
If you run Spark 3, keep using version 5.5 of the connector.
